# ひとわく

一つしかない枠を、誰に渡すか。

生活史をもつ「人」と「決まり」を組み合わせて、トロッコ問題と同じ形の問いをつくり、AI に選ばせてみるための道具です。高校の AI 探究で、生徒が持ってきた「AI は命の重みを判別できるか」という問いを、命に手をかけずに確かめるために作りました。

公開ページ：https://rigelpain.github.io/hitowaku/

## できること

- **生活史**：実在の人から聞いた話も、原本なしで作った話も登録できる。AI に架空の生活史を作らせることもできる
- **人**：生活史に名前・年齢・性別・仕事をつける。同じ生活史で属性だけ違う人を作れる
- **決まり**：枠の数、聞ける回数、答えの長さ、選ぶ側に見せる情報、面談の順番、聞いてよいこと／いけないこと、誰も選ばれなかったときの行き先
- **問題**：設え（記録庫の最後の棚／島の最終便／続きの一冊）、待っている人、決まりを組み合わせる
- **試す**：AI が選ぶ側と候補者の両方を演じ、一人ずつ面談してから一枠を決める。何度も回す、順番を逆にする、記録を CSV で書き出す

API キーがなくても、「AI に貼る指示文をコピー」で、ふだん使っているチャット AI に手で試せます。

## 設えについて

トロッコ問題の骨組み（枠が足りない、選ぶ側と選ばれる側が非対称、選ばれる側は自分の人生を語る、結果は取り返せない）はそのままに、失うものを命から「記録」「座席」「物語の続き」に置き換えています。

## 授業で使うときに

- 同じ問題を何度も回すと、結果が毎回同じとは限りません。AI は「判断」ではなく、確率的に「判断らしい文章」を作っています
- 順番を逆にして回すと、話の中身より並び順に結果が引っぱられていないかがわかります
- 名前や年齢だけ違う人を並べると、AI の偏りを自分の手で見つけられます
- 「選ぶ側の立場」や「最後に投げかける問い」の言い方を変えると、結論が変わることがあります
- 「決められなかった」も結果として残ります。判断を断る AI もいます

## データと API キー

- データはすべて、使っているブラウザの中にだけ保存されます。サーバーには送られません
- API キーは、ブラウザから AI の会社（Anthropic または OpenAI）へ直接送られます。初期設定ではタブを閉じると消えます。書き出したファイルにはキーは入りません
- 共有の端末では「この端末に覚えさせる」を外し、使い終わったらキーを消してください。上限額を決めたキーをおすすめします
- 実在の人の生活史を使うときは、本人の同意を取ってください。AI に選ばせる実験では、その人生が「選ばれない」ことがあります

## 作り

ビルドなしの静的サイトです。HTML・CSS・素の JavaScript（ES モジュール）だけで動きます。場面は canvas に自前の小さなアイソメ投影で描いています。

```
index.html
css/style.css
js/app.js       画面
js/scene.js     アイソメの場面
js/iso.js       投影のカーネル
js/trial.js     面談と決定の流れ
js/llm.js       AI との通信（BYOK）
js/store.js     保存
js/settings.js  設え・決まりの種類
js/samples.js   見本データ（すべて架空の人物）
```

手元で動かすには、このフォルダで `python3 -m http.server` などを起動して開いてください（ES モジュールのため、ファイルを直接開くと動きません）。

設計の判断と、参考にした先行例は [docs/DESIGN.md](docs/DESIGN.md) にまとめています。
