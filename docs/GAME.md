# ひとわく：旅の設計メモ（たたき台）

最初の版の「一枠を誰に渡すか」の部屋は、ここで言う「旅の途中の出来事」の一種になる。人を増やす、選ぶ人を増やす、決め方を変える、をすべて同じ器に載せるため、狭い部屋の会話劇から旅に広げる。

## 決まったこと

- 一行が困難な旅をする。途中で誰かと別れたり、困っている人を助けたりしながら進む
- 犠牲は命ではなく「一行と別れる」（町に残る、別の道を行く）
- 基本はターン制。出来事によってだけ制限時間がつく。完全リアルタイム・並列は、のちの高難易度モード
- 1回の旅はおよそ10分。上手さで短くも長くもなる
- 旅には seed をつけ、同じ旅をいろいろな人で遊べるようにする
- 構成の基本は「高校生1人＋ほかは全部 AI」。全員高校生、全員 AI でも遊べる
- 感情の演出（画面、人の像、吹き出し）は、選ぶ側にも見せる
- 絵は Obra Dinn 風の点描（案C）を土台にし、高校生に届くように少しずつ寄せる
- 出来事の設計は、当面は開発側と AI が担う

## 世界と目的（仮組みの「Last Ship」）

川上の町は、来月ダムの底に沈む。住んでいた人たちは、それぞれの行き先へ散っていった。この一行は、海辺の港から出る最後の船を目指して歩いている。

| 人 | 自分の目的 | 一行の目的に乗る度合い |
| --- | --- | --- |
| 一行 | 港を出る最後の船に全員で乗る | |
| 渡瀬 透 | 全員を船に乗せる | 高い |
| 春日 灯 | 港町で待つ子どもたちに会う | 中くらい |
| 大槻 文雄 | 港町に住む孫に会う。沈む町を離れたくない気持ちもある | 低め |
| 森 由真 | 沈む町と旅の記録を残す | 中くらい |
| ナギ | 途中で拾われた。行き先はまだない | 低い |

- 一行の目的に乗る度合いが低い人は、人に合わせて歩みを落としにくい
- 方針と実際の力は、ふだんは AI が旅ごと（seed ごと）に決める。性格の芯は保ち、細部が変わる。お年寄りの一般常識が当たる旅も、外れる旅もある
- 設定（頭の中の表示、方針の手直し）は Options の奥にある追加要素。何も触らずに遊べる

## 最初の体験（チュートリアル）

1. 生徒は、AI だけの一行が旅をするのを見守る
2. AI たちは出来事のたびに解決策を出し合い、決め方に従って決める
3. 決め方の偏りや、置いていかれる人を見て「これは人間が決めなきゃいけないかも」と感じる
4. 生徒が先導者として入り、決め方を選び、決定を下す側に回る

## 人を見る観点

- 観点（力の種類）は固定しない。プレイヤーが決める。例：体力、知恵、ことば、楽しませる力、芸術、文化、腕っぷし、愛嬌、休みの取り方、着実さ
- AI が、それぞれの人の生活史を読み解いて、プレイヤーが決めた観点に数値を割り振る。数値には、その根拠になった生活史の箇所を添える
- 違う人なのに数値が同じで区別がつかない、という経験を、観点を増やすきっかけにする
- ほかのプレイヤーがつけた観点を見て、借りられる（観点の図書館）。誰がどの観点を使ったかが、人の見方の多様さの記録になる

## 出来事

- 場面ごとに必要な力が入れ替わる（川を渡る＝体力、村との交渉＝ことば・文化、祭り＝芸術・楽しませる力 など）
- 必要な力は「観点」に結びつける。観点がプレイヤー定義なので、出来事の側は「この場面で効きそうな観点」を AI がその場で対応づける
- 困っている人との出会い（仲間が増えるが、食料や席が減る）
- 枠が足りない場面（舟が一艘、食料が数人分）＝最初の版の問題
- 目先の判断と、食料・季節・目的地までの距離という長期の圧力が、交互に効く

## 決め方

出来事ごとに、誰が・どう決めるかを先導者（生徒）が選ぶ。旅の途中で決め方そのものを変えたり、その場で細かな決まりを足したりできる（Frostpunk の法律書のように、決まりの記録が残る）。

候補（歴史上のものを含む）：

| 決め方 | 由来・例 | 何が見えるか |
| --- | --- | --- |
| 一人の長が決める | 君主、家長 | 速いが、長の好みがそのまま出る |
| 輪番 | 持ち回りの当番 | 順番が来た人の価値観が交代で出る |
| 年長者の合議 | 長老会、村の寄合 | 経験の重みと、若い人の声の届きにくさ |
| 全員一致 | 一揆の一味神水、ポーランドの自由拒否権 | 一人の反対で止まる、時間がかかる |
| 多数決 | 直接民主制 | 多数派が少数派を置いていく構造 |
| くじ | アテネの抽選制、くじ引き将軍（足利義教） | 誰の意図も入らない公平さと、その受け入れにくさ |
| 陶片追放 | アテネのオストラシズム | 「誰を外すか」に票を入れる怖さ |
| 代表制（議会） | 代表を選んで代表が決める | 代表に選ばれない人の声の行方 |
| 二院制・拒否権 | 上院・下院、安保理の拒否権 | 決まりの重なりと、特定の席の強さ |
| 株式 | 持ち分に応じた票。持ち分は貢献で増える | 貢献を測る物差しで、誰が強くなるか |
| 順位づけ投票・ボルダ得点 | 選好を順に並べる | 決め方の数え方だけで結果が変わる |
| 二次の投票 | 票を多く入れるほど高くつく | 強い思いをどう数えるか |
| 能力主義 | その場面に強い人が決める | 「強い」の定義を誰が決めるか |
| 当事者が決める・当事者は外す | 別れる候補の人自身の声 | 当事者を入れるかで公平の意味が変わる |
| 占い・神託 | 亀卜、くじ、天候 | 決定の責任を外に預けること |
| AI に任せる | 判断の委任 | 委ねたときの責任の所在 |

- 決め方は組み合わせられる（「まず全員一致を試し、時間切れなら多数決」など）
- 決め方を悪用して、嫌いな人を外すこともできてしまう。それも記録に残し、旅のあとの話し合いで平等・公平・いまの社会の仕組みを考える材料にする

## 頭の中のシミュレーション（仮組み：`prototypes/art/mind.js`）

一般常識と、実際の人と、その人をどう見ているかを分けて持つ。歩く速さで最初に試した。

| 持つもの | 中身 |
| --- | --- |
| 一般常識 | 「お年寄りはこれくらいの速さで歩く」という、皆が共有している思い込み |
| 実際の力 | その人が本当に歩ける速さ。最初は誰も知らない |
| 見積もり | ある人が別の人の速さをどう見ているか。最初は一般常識から |
| 自分の見積もり | 自分がどれくらい歩けると思っているか。最初は自分にも一般常識が当てはまる |
| 方針 | 合わせるか、観察するか、学ぶか、自覚するか、言うか（伝える／方針だけ言う／内心にとどめる）、人の話を信じるか |
| 自分についての方針 | 思い込みの強さ（自分の見積もりに歩みが引っ張られる）、自分を知る（体の手応えで見積もりを直す）、人の見方に左右される（人が自分をどう見ているかを取り込む） |

- 本人の思い込みで、力より遅く歩くことがある。周りが「お年寄りだから」と合わせると、その見方が本人に伝わり、思い込みが強まることもある
- 実在の人の生活史を使わずに、思い込み・自己理解・他者への依存の組み合わせを試せる

- 方針は人が決めても AI が決めてもよい。仮組みでは Minds パネルで一人ずつ変えて、やり直せる
- 合わせて歩くと、相手の本当の速さが見えにくくなる。気づくきっかけは、観察か、本人の言葉か
- 内心・発話・聞いたこと・行動（自覚のない変化を含む）をログに残す。画面では Thoughts・Talk・Log・Minds で出し入れする

## 旅のあと

- 誰がどの決め方で、どの出来事で、一行と別れたかの年表
- 同じ seed の旅をほかの人がどう進めたかとの比較
- 演出なしで同じ会話を読み直す画面（印象がどう変わるかを書き留める）

## 安全のために最初から入れること

- 演出の強さを授業者が決められる（0〜3段階）。生徒もいつでも止められる
- 光の点滅は1秒に3回以下に抑え、画面の大部分を一気に光らせない。「動きを減らす」設定では揺れを止め、色の変化だけにする
- 実在の生活史では、強い演出を既定で切る

## のちに考えること

- 高難易度モード（完全リアルタイム、並列の出来事）
- 生徒が出来事を設計する側に回る
- 人が地形を歩く経路探索（必要になったら recast-navigation-js）
