3D を描けませんでした

このブラウザでは、いま WebGL（3D の描画）が使えない状態です。多くの場合、ブラウザの設定で GPU が使われていないことが原因です。

Chrome
設定 → システム →「グラフィック アクセラレーションが使用可能な場合は使用する」をオンにして、ブラウザを開き直す
Edge
設定 → システムとパフォーマンス →「グラフィック アクセラレーションが使用可能な場合は使用する」をオンにして、開き直す
Safari
macOS と Safari を新しい版にして、開き直す
Firefox
設定 → 一般 → パフォーマンス →「ハードウェアアクセラレーションを使用する」をオンにして、開き直す
ほかに
別のブラウザで開く。学校の端末では、管理の設定で GPU が止められていることもある
